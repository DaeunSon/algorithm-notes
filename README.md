# algorithm-notes

자료구조와 알고리즘을 개념 노트와 직접 구현으로 정리하는 저장소입니다.
문제 풀이는 이 저장소에 두지 않고, 노트의 "연습 문제" 표에 링크로 연결합니다.

## 공부 흐름

1. 개념: 작은 예시를 손으로 추적한다
2. 구현: 코드를 보지 않고 백지에서 직접 구현한다
3. 노트: 해당 폴더의 `README.md`를 내 말로 채운다 (특히 판별 단서)
4. 연습: 같은 유형 문제를 풀고 노트의 표에 링크를 남긴다
